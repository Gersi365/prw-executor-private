LOCKED STATE MODEL

- Healthy: new Request sends are admitted.
- WritePoisoned: no further Request send is admitted on the same connection-state instance.
- Only transition: Healthy -> WritePoisoned.
- WritePoisoned is absorbing; there is no reset transition on the same state object.

SEND SEMANTICS

- Pre-existing WritePoisoned state rejects before frame build, tracker registration, and writer I/O.
- Phase 033 build failure leaves the state Healthy.
- Phase 033 registration failure leaves the state Healthy.
- Any Phase 033 generic write failure transitions the state to WritePoisoned before returning the nested error.
- A write-failed request remains outstanding according to the Phase 033 contract.
