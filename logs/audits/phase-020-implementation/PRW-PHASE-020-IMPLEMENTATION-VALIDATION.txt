LOCKED INVARIANT

Terminal response outer-kind mapping:
- LocalAgentResponseStatus::Ok -> LocalIpcMessageKind::Response
- every current non-Ok response status -> LocalIpcMessageKind::Error

Therefore:
- Response + non-Ok is invalid;
- Error + Ok is invalid;
- Request is never a terminal response.

Phase 020 operates only on an already validated LocalIpcFrame. Existing frame constructors remain authoritative for supported protocol version, non-zero typed request ID, globally bounded payload, and exact declared-vs-actual payload length. Phase 020 does not duplicate those checks.
