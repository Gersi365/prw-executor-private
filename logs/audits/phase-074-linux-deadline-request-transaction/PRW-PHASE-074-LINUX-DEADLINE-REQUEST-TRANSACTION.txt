ORDERING

For one authenticated Request attempt:

1. start one absolute read deadline immediately before boundary frame acquisition;
2. create a deferred write adapter without starting its deadline;
3. reuse the existing Phase 051 boundary-aware aggregate state pipeline;
4. read/decode the complete Request and build the policy-gated terminal response;
5. start the independent absolute write deadline only on the first non-empty response write;
6. preserve existing inbound-read and response-write poison transitions.

Clean EOF never starts the deferred write deadline.
