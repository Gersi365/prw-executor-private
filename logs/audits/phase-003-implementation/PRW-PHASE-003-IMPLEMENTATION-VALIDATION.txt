DECISION

The initial device-identity signature primitive is ECDSA over NIST P-256 with SHA-256.
Repository algorithm identifier: EcdsaP256Sha256.

This lock applies only to device identity. Device identity and future transport identity remain separate cryptographic roles.

RATIONALE BOUNDARY

The decision was made from primary platform and standards evidence:
- NIST FIPS 186-5 defines ECDSA as a digital-signature technique.
- NIST SP 800-186 specifies recommended elliptic-curve domain parameters including NIST prime curves.
- Android Keystore documentation supports EC key generation through KeyGenParameterSpec from API level 23 and provides a NIST P-256 signing example.
- Android Signature API documents Ed25519 from API level 33.

For the current Ubuntu + Android targets, P-256 therefore provides a broader route to Android OS-backed key storage than an Ed25519-only baseline while remaining a standardized cross-platform signature primitive.

This is an architecture inference from platform compatibility and standards. It does not assert identical hardware-backed security across Android devices.
