IMPLEMENTED WRITE ORDER

The generic writer emits one complete validated frame in this exact order:
1. encode the validated header through the Phase 009 codec;
2. write all 24 header bytes;
3. only after the header completes, write all bounded payload bytes;
4. return without separators, padding, trailers, or implicit flush.

The writer never recomputes, clamps, truncates, pads, or silently rewrites the Phase 010 payload-length relationship.
