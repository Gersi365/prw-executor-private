LOCKED ORDERING

For streamed successful GetAgentStatus responses:
1. acquire one complete validated frame through the Phase 024 read path;
2. validate terminal Response+Ok semantics and fully decode the fixed five-byte Agent status body;
3. obtain the typed request ID from the fully decoded result;
4. complete exactly that ID through LocalRequestTracker::complete();
5. return the decoded result only after tracker completion succeeds.

Tracker state remains unchanged for generic frame-read failures and command-specific decode failures. A fully decoded unknown request ID also leaves unrelated outstanding requests unchanged.
