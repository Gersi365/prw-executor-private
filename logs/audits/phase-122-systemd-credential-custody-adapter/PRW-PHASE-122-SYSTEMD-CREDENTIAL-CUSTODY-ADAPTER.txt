FIXED CREDENTIAL IDENTITY

The adapter reads exactly:
`prw.device-identity.private-key.v1`

The credential is resolved only relative to the systemd-provided environment value:
`CREDENTIALS_DIRECTORY`

There is no fallback to:
- `${XDG_STATE_HOME}` plaintext;
- `$HOME/.local/state` plaintext;
- `/run/credentials/...` hardcoded paths;
- the Phase 118 encrypted blob filename;
- arbitrary caller-supplied files.

ENVIRONMENT / DIRECTORY BOUNDARY

`CREDENTIALS_DIRECTORY` must:
- be present;
- be non-empty;
- resolve to an absolute path.

The directory is examined with `symlink_metadata` and must:
- not be a symlink;
- be a directory;
- be owned by the effective service user;
- not be group- or other-writable;
- retain owner read/search access.

The precise real systemd user-manager ownership/mode compatibility of these checks remains subject to the Phase 123 real-host delivery proof before Agent/service integration.

CREDENTIAL FILE SHAPE / RACE-RESISTANT OPEN

The exact named credential is preflighted with `symlink_metadata`.

It must:
- exist;
- not be a symlink;
- be a regular file;
- be owned by the effective service user;
- not be group- or other-writable;
- not have execute bits;
- be owner-readable;
- not exceed the signer maximum before opening.

The adapter then opens the path read-only using rustix with:
- `O_RDONLY`;
- `O_CLOEXEC`;
- `O_NOFOLLOW`.

After opening, metadata is read from the opened descriptor and the adapter requires:
- regular-file type;
- identical device number to the pre-open object;
- identical inode to the pre-open object;
- the same ownership/permission policy.

This prevents a normal path-following fallback and detects replacement between the preflight metadata read and the opened descriptor.

BOUNDED PLAINTEXT ACQUISITION

The maximum accepted plaintext private credential remains the Phase 120/121 signer bound:
4096 bytes.

The adapter reads at most 4097 bytes from the opened descriptor using a bounded reader.

It fails closed if:
- the resulting payload is empty;
- payload length exceeds 4096 bytes;
- a read operation fails.

The plaintext read buffer is owned by:
`Zeroizing<Vec<u8>>`

The buffer is temporary and is dropped after the signer construction attempt, whether construction succeeds or fails.

PRW does not implement custom unsafe memory wiping. Workspace `unsafe_code = "forbid"` remains intact.

CANONICAL PAYLOAD ENFORCEMENT

After bounded acquisition, the adapter calls:
`UbuntuEnrollmentSigner::from_pkcs8_v1_der(...)`

Therefore Phase 121 canonical signer checks remain the final private-key payload gate.

Malformed, truncated, wrong-profile, alternate-format, or trailing-content input is rejected by the signer boundary.

A test explicitly appends a newline to an otherwise valid disposable PKCS#8 payload and proves failure as `InvalidPrivateCredential`; the adapter does not trim, normalize, decode, or otherwise reinterpret private-key bytes.

ERROR / SECRET DISCLOSURE BOUNDARY

- unsupported platform;

Errors contain no:

The adapter itself emits no logs and has no secret-bearing Debug type.
