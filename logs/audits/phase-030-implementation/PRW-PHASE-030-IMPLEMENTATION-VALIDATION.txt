LOCKED ORDERING

For streamed successful GetPrivateDnsConfig responses:
1. acquire one complete validated frame through the Phase 029 read path;
2. validate terminal Response+Ok semantics;
3. fully decode and validate the bounded Phase 027 private-DNS body;
4. obtain the typed request ID from the fully decoded result;
5. complete exactly that ID through LocalRequestTracker::complete();
6. return the decoded result only after tracker completion succeeds.

Tracker state remains unchanged for generic frame-read failures and bounded command-specific decode failures. A fully decoded unknown request ID also leaves unrelated outstanding requests unchanged.
