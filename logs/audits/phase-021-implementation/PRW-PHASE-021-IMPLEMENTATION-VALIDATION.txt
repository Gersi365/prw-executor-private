LOCKED TRANSACTION ORDER

1. validate the frame through the Phase 020 terminal-response validator;
2. obtain the existing typed request ID from the validated response;
3. complete that ID through LocalRequestTracker::complete();
4. return the terminal response only after completion succeeds.

Invalid terminal frames do not mutate request-tracker state. A valid terminal response for an unknown request ID does not remove any other request. A successfully completed ID is removed exactly once; replay then fails as UnknownRequestId until explicit re-registration.
