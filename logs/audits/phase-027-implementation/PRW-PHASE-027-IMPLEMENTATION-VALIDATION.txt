- byte 0: flags

  - bit 1 = device_naming

- byte 1: resolver count, additionally bounded to <=16
- byte 2: split-domain count, additionally bounded to <=64

Each entry is encoded as:
- u16 big-endian UTF-8 byte length
- exactly that many UTF-8 bytes
