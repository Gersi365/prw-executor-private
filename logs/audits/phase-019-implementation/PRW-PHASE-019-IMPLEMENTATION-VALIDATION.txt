LOCKED SUCCESS PAYLOAD

A successful GetAgentStatus command payload is exactly 7 bytes:
- bytes 0..1: LocalAgentResponseStatus::Ok as big-endian u16 (00 00)
- byte 2: runtime-state u8
- bytes 3..4: protocol-major big-endian u16
- bytes 5..6: protocol-minor big-endian u16

Current Ready / protocol 1.0 success bytes:
00 00 02 00 01 00 00

The implementation composes the existing Phase 016 response-status codec with the existing Phase 018 Agent-status body codec. It does not duplicate either mapping.
