LINUX SEMANTIC FIT

Linux `signalfd` is explicitly monitorable by `poll`/`epoll` and should be used with the selected signals blocked so default signal disposition cannot consume them asynchronously.

POSIX/Linux thread semantics establish that a newly created thread inherits a copy of its creator's signal mask. Therefore the PRW production signal mask must be established on the runtime thread before the Phase 097 `std::thread::scope` creates session workers.

The Phase 094-A01 signal candidates remain exactly:
- SIGTERM;
- SIGINT.

SIGHUP reload remains deferred.

PRW SIGNAL OWNERSHIP REQUIREMENT

The future signal source must:
1. create a mask containing SIGTERM and SIGINT;
2. atomically/synchronously preserve the prior calling-thread mask while blocking the termination mask;
3. create a CLOEXEC + NONBLOCK SignalFd for exactly that termination mask;
4. ensure all Phase 097 worker threads are created after the mask is installed;
5. expose the SignalFd only as a pollable/readable safe wrapper;
6. explicitly restore the prior thread signal mask after listener/socket cleanup;
7. best-effort restore the mask on unwind;
8. preserve an original runtime/lifecycle terminal reason independently from mask-restoration failure.

SIGNAL-AWARE READINESS REQUIREMENT

A future Phase 098 adapter must implement semantic precedence:

1. termination SignalFd readiness;
2. Phase 089 runtime wake readiness;
3. listener readiness.

It must preserve Phase 091 capacity-aware listener suppression at full worker capacity.

A termination signal observation must establish terminal shutdown before any simultaneous listener dispatch. No accepted connection may begin after a SIGTERM/SIGINT observation in the same readiness result.

TEST ISOLATION REQUIREMENT

Process-global/thread signal-mask tests must not mutate the ordinary parallel Rust test harness's signal state.

Real SIGTERM/SIGINT delivery and mask/signalfd behavior must therefore be validated in a dedicated child-process/subprocess boundary. Pure readiness classifiers may remain ordinary deterministic unit tests.
