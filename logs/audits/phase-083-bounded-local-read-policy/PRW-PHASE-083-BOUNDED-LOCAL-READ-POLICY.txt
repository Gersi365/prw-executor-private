MODEL

BoundedLocalReadPolicy is a Copy value type holding exactly two decisions:

- AgentStatusRead;
- PrivateDnsConfigRead.

Evaluation is a fixed in-memory match. The two implemented local read capabilities return their stored decision. Every other represented capability returns Deny fail-closed.

The evaluator performs no allocation, filesystem/network I/O, synchronization, callbacks, external lookup, or mutable state access.

SECURITY BOUNDARY

BoundedLocalReadPolicy does not authenticate a principal. Runtime code must select/use it only after the relevant authentication boundary.

For the initial local same-UID Agent worker path, this is the only concrete policy implementation authorized for scheduler binding. Arbitrary PolicyEvaluator implementations remain outside the initial runtime boundary because the generic synchronous trait does not guarantee bounded/non-blocking evaluation.
