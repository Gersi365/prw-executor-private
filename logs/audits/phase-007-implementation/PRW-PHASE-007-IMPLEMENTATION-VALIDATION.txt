LOCKED FRAMING BOUNDARY

Local IPC version 1.0 uses:
- fixed 24-byte frame header;
- magic bytes PRW\0;
- unsigned 16-bit major/minor version fields;
- Request / Response / Error message kinds;
- non-zero unsigned 64-bit request ID;
- unsigned 32-bit payload length;
- network byte order for multi-byte wire integers;
- maximum opaque payload length 1,048,576 bytes (1 MiB);
- exact version 1.0 support only until future compatibility rules are explicitly locked.

Version-1.0 message-kind codes:
- 1 Request
- 2 Response
- 3 Error

Request IDs are correlation metadata only and are not authentication tokens, capabilities, secrets, or durable object identifiers.
