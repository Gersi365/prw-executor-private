PURPOSE

Implement the first Phase 072 wait-bound primitive while preserving the existing blocking accepted-stream model and without spawning workers, accepting connections, or activating the Agent runtime.

IMPLEMENTED

- source: crates/prw-agent/src/linux_deadline_io.rs
- Linux platform integration: crates/prw-agent/src/linux_identity.rs
- architecture: docs/architecture/PHASE_073_LINUX_ABSOLUTE_DEADLINE_IO.md

MODEL

- LocalLinuxIoBudget accepts only strictly positive Duration values.
- LocalLinuxDeadlineReader computes one monotonic absolute deadline when the read phase starts.
- LocalLinuxDeadlineWriter computes one independent monotonic absolute deadline when the write phase starts.
- Before every underlying blocking read/write call, the remaining time until the same stored deadline is recomputed.
- The corresponding UnixStream read/write timeout is set to no more than the remaining duration.
- Partial progress does not replace or extend the stored absolute deadline.
- timeout-style WouldBlock/TimedOut errors are normalized to std::io::ErrorKind::TimedOut inside the adapter.
- an unrepresentable now+budget deadline is rejected before I/O.

VALIDATED BEHAVIOR

Linux runner tests prove:

- zero Duration is rejected;
- unrepresentable monotonic deadline is rejected;
- independent read/write deadline adapters round-trip bytes over UnixStream::pair();
- successful partial read progress leaves the reader absolute deadline unchanged;
- successful write progress leaves the writer absolute deadline unchanged;
- an idle peer read expires and is surfaced as TimedOut.
