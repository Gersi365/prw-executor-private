Phase 009 implements a pure in-memory codec for the fixed 24-byte local IPC header locked by Phase 007.

Encoder:
- accepts an already validated LocalIpcFrameHeader;
- emits exactly 24 bytes;
- emits PRW\0 magic;
- uses big-endian encoding for version, request ID, and payload length;
- emits zero version-1.0 flags and reserved bytes;
- performs no socket I/O and no payload processing.

- accepts exactly one 24-byte header array;
- validates magic;
- rejects unknown message kind;
- rejects non-zero version-1.0 flags;
- rejects non-zero version-1.0 reserved bytes;
- rejects request ID zero;
- rejects unsupported protocol version;
- rejects payload length above the Phase 007 1 MiB global bound;
- routes reconstructed typed values through existing validators;
- performs no payload allocation or parsing.
