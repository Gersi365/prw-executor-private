PURPOSE

Compose the Phase 059 same-UID-authenticated Linux connection wrapper with the Phase 052 bounded provider-neutral application loop and one owned LocalServerConnectionState, without creating a listener or filesystem socket lifecycle.

IMPLEMENTED

- source: crates/prw-agent/src/linux_authenticated_session.rs

- contract: contracts/LINUX_AUTHENTICATED_APPLICATION_SESSION_CONTRACT.md
- architecture: docs/architecture/PHASE_060_LINUX_AUTHENTICATED_APPLICATION_SESSION.md

TYPE-LEVEL ORDERING

Raw connected stream -> Phase 059 wrapper constructor -> Phase 058 kernel SO_PEERCRED same-effective-UID authorization -> AuthenticatedLocalLinuxConnection -> AuthenticatedLocalLinuxSession -> Phase 052 bounded application processing.

The Phase 060 session constructor does not accept a raw stream. Its processing method operates only on the already-authenticated connection it owns.

The session also owns the aggregate LocalServerConnectionState, so inbound/read poisoning and response-write poisoning persist across bounded processing invocations exactly as defined by Phases 044-052.

POLICY BOUNDARY

The PolicyEvaluator remains caller-supplied. Same-UID transport authentication does not claim or manufacture principal-to-capability binding. Phase 060 preserves that separation explicitly.

VALIDATED BEHAVIOR

Linux anonymous UnixStream::pair tests validate:
- bounded processing of authenticated Requests and correlated responses;
- clean EOF remains a normal stop;
- malformed/truncated authenticated input updates the session-owned aggregate state to InboundRead;
- peer credentials retained by the session match the effective Agent UID.

No filesystem Unix socket pathname or listener is created by these tests.
