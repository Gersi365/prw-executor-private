LOCKED BOUNDARY

The future Ubuntu Desktop/CLI-to-Agent local IPC baseline is:
- filesystem-backed AF_UNIX SOCK_STREAM socket;
- endpoint $XDG_RUNTIME_DIR/private-remote-workspace/agent.sock;
- PRW runtime subdirectory mode 0700;
- socket filesystem mode 0600;
- peer credentials obtained from Linux SO_PEERCRED;
- baseline authorization requires the kernel-reported peer UID to match the Agent UID expected by local policy;
- no TCP, loopback-TCP, /tmp, or Linux abstract-socket fallback.

The contract requires fail-closed behavior if required XDG runtime-directory security properties cannot be established.
