LOCKED STATE BOUNDARY

Each future local IPC connection may have at most 64 simultaneously outstanding request IDs.

Registration rules:
- duplicate currently outstanding ID -> DuplicateRequestId;
- tracker already at 64 outstanding IDs -> TooManyOutstandingRequests;
- duplicate detection is evaluated before capacity failure.

Completion rules:
- known outstanding ID is removed after one terminal Response or Error;
- unknown/stale/unsolicited ID -> UnknownRequestId;
- an ID may be reused only after its previous exchange is completed and removed.

Request IDs remain ephemeral correlation metadata, not secrets, authentication tokens, capabilities, cryptographic nonces, or durable object identifiers.
