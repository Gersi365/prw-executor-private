LOCKED STATUS MODEL

Phase 017 defines a minimal read-only status snapshot for a future successful GetAgentStatus response.

Runtime-state identifiers:
- Starting -> 1
- Ready -> 2
- Degraded -> 3
- Stopping -> 4

The snapshot also carries the current LocalIpcProtocolVersion. No hostname, PID, timestamp, filesystem path, build metadata, DNS configuration, network addresses, or other host metadata is included.
