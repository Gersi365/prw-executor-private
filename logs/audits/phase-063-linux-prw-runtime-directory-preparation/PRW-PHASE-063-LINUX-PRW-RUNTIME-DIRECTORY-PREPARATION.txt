PRODUCTION ALGORITHM

- input is a ValidatedXdgRuntimeRoot, not a raw runtime-root pathname;
- mkdirat attempts only the fixed private-remote-workspace child at requested mode 0700;
- EEXIST is never trusted as success by itself;
- openat is relative to the retained validated root descriptor with RDONLY | DIRECTORY | NOFOLLOW | CLOEXEC;
- fstat proves directory type and effective-UID ownership before any repair;
- only a verified same-UID PRW child may be normalized with descriptor-based fchmod to exact 0700;
- descriptor metadata is revalidated after normalization;
- success returns an owned ValidatedPrwRuntimeDirectory descriptor.

VALIDATED BEHAVIOR

Temporary runner filesystem tests prove:
- absent PRW child is created and validated at 0700;
- pre-existing same-UID 0755 child is normalized to exact 0700;
- symlink child fails closed and its target is not modified;
- regular-file child fails closed;
- wrong-owner metadata classification fails before mode policy;
- descriptor anchoring survives rename/replacement of the original XDG-root pathname: the child is created beneath the renamed original validated directory, not beneath the replacement pathname.
