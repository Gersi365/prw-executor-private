OWNERSHIP DESIGN

Phase 096 deliberately avoids a self-referential owner struct.

The existing accept-ready listener ultimately borrows the validated PRW runtime directory and Agent instance lock. Phase 096 therefore uses a callable scoped assembly function that owns the root/directory/lock/listener stack locally and lends the live listener/wake/capacity/control references only for the callback lifetime.

This preserves workspace `unsafe_code = "forbid"` and keeps owner/borrow ordering explicit.

ASSEMBLY ORDER

1. validate `$XDG_RUNTIME_DIR` with existing Phase 062 descriptor policy;
2. prepare/validate the fixed PRW runtime child;
3. acquire the nonblocking exclusive Agent instance lock;
4. bind the exact validated Agent Unix socket;
5. enter listening state using the explicit Phase 095 backlog;
6. enter verified nonblocking accept-ready state;
7. create the Phase 089 runtime wake eventfd;
8. create configured Phase 075 worker-capacity accounting;
9. create monotonic Phase 086 scheduler control;
10. invoke the bounded callback while all lifecycle resources are live;
11. explicitly clean the listener/socket path before descriptor owners unwind.

ROLLBACK SEMANTICS

- failures before bind unwind owned descriptors without a live listener;
- listen transition failure recovers the bound socket through `into_parts()` and performs exact-identity cleanup;
- accept-ready transition failure recovers the listening socket through `into_parts()` and performs exact-identity cleanup;
- runtime-wake creation failure after listener setup performs explicit listener/socket cleanup before return;
- stage error and cleanup evidence are preserved separately;
- cleanup failure never replaces the original assembly-stage failure.

UNWIND SEMANTICS

A private listener cleanup guard owns the accept-ready listener while the callback runs.

- normal callback return performs explicit cleanup and returns the cleanup classification;
- callback panic unwinds through the guard, which performs best-effort listener/socket cleanup before instance-lock/runtime-directory ownership unwinds;
- the guard does not swallow or transform the panic.

VALIDATED PROOFS
