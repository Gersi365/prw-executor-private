PRODUCTION ALGORITHM

- input is a ValidatedPrwRuntimeDirectory;
- open/create fixed agent.lock relative to its descriptor;
- RDWR | CREATE | NOFOLLOW | CLOEXEC | NONBLOCK;
- creation mode 0600;
- fstat requires regular-file type and effective-UID ownership before repair;
- same-UID regular lock file may be fchmod-normalized to exact 0600 and revalidated;
- nonblocking exclusive flock;
- EWOULDBLOCK/EAGAIN becomes AlreadyRunning;
- any other flock error fails closed;
- success returns an AgentInstanceLock that owns the locked descriptor;
- dropping the guard releases the advisory lock through descriptor closure but does not unlink agent.lock.

VALIDATED BEHAVIOR

Temporary runner tests prove:
- absent lock file is created and validated at 0600;
- a second conforming acquisition while the first guard is alive returns AlreadyRunning;
- the persistent lock file can be locked again after the first guard is dropped;
- pre-existing same-UID 0644 lock file is normalized to 0600;
- a final-component symlink fails closed without changing its target;
- wrong-owner metadata classification fails before mode policy.
