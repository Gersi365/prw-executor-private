ERROR DISPOSITION

Locked Phase 094-A01 policy is represented explicitly:

- same-UID peer-authorization rejection => `ContinueAfterPeerRejection`;
- readiness failures => `FailStop`;
- ordinary accept failure => `FailStop`;
- cancellation clone failure => `FailStop`;
- worker spawn failure => `FailStop`.

Fatal errors preserve exact readiness/scheduling classification rather than collapsing to a generic failure.

TERMINAL EVIDENCE

`LocalLinuxProductionRuntimeTerminalReport` keeps:

- original terminal reason;
- process-lifetime aggregate counters;
- final cancellation outcomes;
- final joined worker completions;
- listener/socket cleanup outcome.

Final cancellation/completion vectors are bounded by configured maximum worker capacity rather than growing with daemon lifetime. Cleanup failure is represented independently and does not overwrite the terminal reason.
