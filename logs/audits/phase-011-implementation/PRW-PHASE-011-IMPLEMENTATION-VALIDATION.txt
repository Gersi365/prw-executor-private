IMPLEMENTED READ ORDER

The generic reader acquires one complete frame in this exact order:
1. read exactly 24 header bytes;
2. decode and validate through the Phase 009 codec;
3. reject invalid header metadata before payload allocation/read;
4. checked conversion of validated u32 payload length to usize;
5. allocate exactly the validated payload length;
6. read exactly that payload length;
7. construct the Phase 010 bounded payload;
8. couple header and payload into a Phase 010 LocalIpcFrame;
9. leave following stream bytes unread.

This preserves the Phase 007 1 MiB payload ceiling before receive allocation.
