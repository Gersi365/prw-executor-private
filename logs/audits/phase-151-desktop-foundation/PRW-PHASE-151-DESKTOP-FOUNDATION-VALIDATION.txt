LOCAL IPC TRUST BOUNDARY

The desktop client derives only the fixed existing endpoint:
$XDG_RUNTIME_DIR/private-remote-workspace/agent.sock

Before connection, the desktop client fails closed unless:
- XDG_RUNTIME_DIR is absolute;
- the runtime root is a directory with mode 0700;
- the runtime root owner equals the desktop process effective UID;
- the PRW runtime child directory is a directory with mode 0700 and the same effective UID owner;
- agent.sock is a Unix-domain socket with mode 0600 and the same effective UID owner.

The Agent remains authoritative for same-effective-UID peer authorization using the existing Linux peer-credential boundary.

No TCP fallback, shell bridge, arbitrary-command proxy, privileged desktop helper, or alternate endpoint was introduced.

FUNCTIONAL BOUNDARY

Phase 151 is intentionally read-only.

The desktop source reads only:
- GetAgentStatus;
- GetPrivateDnsConfig.

It does not implement terminal execution, file operations, transfers, forwarding mutation, network mutation, DNS mutation, remote desktop capture/streaming, input injection, clipboard synchronization, or multi-monitor control.
