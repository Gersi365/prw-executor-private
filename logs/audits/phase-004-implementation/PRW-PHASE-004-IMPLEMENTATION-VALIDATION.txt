DECISIONS

1. Device identity public-key encoding
- Repository identifier: SubjectPublicKeyInfoDer
- Meaning: DER-encoded X.509 SubjectPublicKeyInfo.
- ECC algorithm identifier: id-ecPublicKey.
- Named curve: secp256r1 / NIST P-256.
- Standards basis: RFC 5480.

2. Device identity signature encoding
- Repository identifier: EcdsaSigValueDer
- Meaning: DER-encoded RFC 3279 ECDSA-Sig-Value.
- ASN.1 structure: SEQUENCE { r INTEGER, s INTEGER }.

3. Explicit metadata rule
- Algorithm and encoding identifiers are carried explicitly.
- They must not be inferred from byte length, byte prefix, or platform origin.
- Signature bytes are not stable object identifiers.
