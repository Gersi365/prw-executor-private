LOCKED REQUEST PAYLOAD

The two current read-only local Agent commands use an exact two-byte request payload:
- unsigned 16-bit command identifier;
- big-endian/network byte order;
- no request argument bytes.

Mappings:
- GetAgentStatus (code 1) -> 00 01
- GetPrivateDnsConfig (code 2) -> 00 02

Decode rules:
- payload length must be exactly two bytes;
- command code must map to the active typed command namespace;
- short/trailing payloads are rejected as InvalidLength;
- unknown identifiers are rejected as UnknownCommand;
- no raw/generic command fallback is permitted.
