RUNTIME WAKE SEMANTICS

- one LocalLinuxRuntimeWake owns single-consumer drain authority;
- cloneable LocalLinuxRuntimeWakeNotifier values expose only notification API;
- one shared Arc-backed eventfd lifetime supports multiple writers and one drainer;
- eventfd is created with initial counter 0, CLOEXEC and NONBLOCK, without SEMAPHORE;
- notify writes fixed native-endian 1_u64;
- notify retries only EINTR for the same fixed write;
- notify EAGAIN maps to AlreadyPending;
- short writes and other write failures fail closed;
- drain retries only EINTR for the same fixed read;
- drain requires exactly eight bytes, nonzero value and non-u64::MAX value;
- drain EAGAIN maps to WouldBlock;
- numeric eventfd count is not exposed as semantic runtime event data.
