CANCELLATION AUTHORITY

LocalLinuxWorkerCancellation is constructible only from an already-authenticated AuthenticatedLocalLinuxConnection<UnixStream>.

Construction calls UnixStream::try_clone and retains the independently owned handle solely for terminal shutdown. The wrapper exposes no application Read/Write interface.

cancel() issues shutdown(Shutdown::Both) and returns a bounded ShutdownFailed error if the operating system rejects the call.

REGISTRY PAIRING

Each Phase 080 registry entry now owns exactly:

- one ScopedJoinHandle for the worker;
- one LocalLinuxWorkerCancellation for the same underlying authenticated connection.

cancel_all() issues shutdown on every retained cancellation authority without removing any worker handle.

reap_finished() removes a finished entry, joins/classifies the worker through Phase 079, then drops the matching cancellation authority.

join_all() joins/classifies all remaining workers and drops every paired cancellation authority.

VALIDATED SHUTDOWN BEHAVIOR

Linux runner tests prove:

- cancellation clone construction occurs after same-UID authenticated wrapping;
- shutdown(Both) is terminal for the shared connected stream;
- finished-worker reaping leaves a running worker and its cancellation authority registered;
- cancel_all() does not remove the worker handle and mandatory join remains possible;
- a real Phase 078 worker blocked with a 5-second Request-read deadline is woken and joined in less than 2 seconds after cancel_all();
- the worker-capacity count returns to zero after cancellation and join;
- the cancellation terminal result may surface as clean EOF or the existing bounded worker error depending on kernel read completion semantics, and both are explicitly classified.
