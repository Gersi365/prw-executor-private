LOCKED ARCHITECTURE

- capacity-aware blocking poll;
- one shared non-semaphore Linux eventfd as coalescing runtime wake transport;
- eventfd flags: initial 0, CLOEXEC, NONBLOCK, no SEMAPHORE;
- runtime wake always armed;
- listener armed only while active_workers() < max_workers();
- worker-completion and terminal-shutdown wake producers share the wake transport;
- eventfd counter carries no semantic event count;
- fixed native-endian u64 value 1 for notification;
- eventfd read/write retry only EINTR for the same fixed operation;
- write EAGAIN means wake already pending;
- short I/O and unexpected drain/readiness states fail closed;
- blocking poll uses no timeout;
- poll EINTR is surfaced as structured WaitInterrupted and is not internally retried;
- runtime wake precedence over simultaneous listener readiness;
- wake handling re-observes shutdown, reaps finished workers, then recomputes capacity;
- worker completion wake is implemented outside LocalLinuxWorkerPermit accounting and after permit release/unwind;
- registry cancel_all() precedes join_all() at shutdown;
- all scoped worker handles remain inside one std::thread::scope lifetime.
