PRIMARY-SOURCE REVIEW
Phase 139 reviewed current upstream specifications/documentation before selecting the stack. QUIC v1 and QUIC-TLS are standardized by RFC 9000/RFC 9001. The current Quinn 0.11.11 feature model provides runtime-tokio and rustls-aws-lc-rs while its default feature set would also enable platform-verifier/rustls-ring/bloom, so PRW explicitly disables default features. Quinn's current 0.11 line does not provide the required initial QUIC-v2 compatibility lock, so PRW starts with QUIC v1. rustls 0.23.43 is the current pinned PRW line and contains QUIC-related fixes; Tokio 1.53.1 is the selected async runtime version. ICE RFC 8445, STUN RFC 8489 and TURN RFC 8656 are locked as the Phase 141 traversal standards, while their exact Rust implementation dependency remains separately gated for current-library validation.

ARCHITECTURE OUTCOME
The existing Phase 129 control plane remains TCP/TLS 1.3 and is not repurposed as the mesh data plane. The new data plane is QUIC v1 over UDP with TLS 1.3, mutual TLS, ALPN prw-mesh/1, explicit PRW private trust roots and reliable QUIC streams. No plaintext fallback, custom dangerous verifier, public/OS trust fallback, 0-RTT, initial resumption, application QUIC DATAGRAM or initial active-migration policy is allowed.

IDENTITY OUTCOME
DeviceId, the Phase 126 device-identity key and the mesh TransportIdentity remain separate. The transport key is a separate locally generated ECDSA P-256 key. TransportIdentity is SHA-256 of the canonical leaf SPKI DER. Transport certificates are short-lived PRW-private-CA X.509 leaves with clientAuth/serverAuth usage. The Phase 126 identity authorizes issuance/renewal but is not reused as the TLS key.

PEER-NAME OUTCOME
The TLS SAN/SNI identity derives deterministically from the full TransportIdentity as t-<first32hex>.<last32hex>.mesh.prw.invalid. This name is certificate identity only and is never DNS-resolved for endpoint discovery; the selected candidate provides an explicit IP/UDP endpoint. Standard rustls/WebPKI verification remains in force.

CERTIFICATE LIFECYCLE OUTCOME
Initial leaf maximum validity is 30 days; renewal begins with 10 days or less remaining. Registry revocation overrides certificate expiry state. Transport-CA signing keys never live on the Agent/client. Transport-key rotation creates a new TransportIdentity and requires registry transition/revocation handling.

FRAMING OUTCOME
The reserved mesh control stream uses a bounded 24-byte PRWM v1.0 envelope with non-zero request IDs and maximum 65,536-byte control payloads. Initial kinds are session-auth, request, response, event, heartbeat and error. Malformed/unknown-major/oversize/truncated frames fail closed. Bulk file/terminal/forwarding stream schemas remain deferred to Phase 143.

Initial validation limits include at most 32 remotely initiated bidirectional streams and 16 remotely initiated unidirectional streams, plus finite handshake/idle/read/write/cancellation bounds chosen and tested by Phase 140.
